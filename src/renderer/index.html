Welcome to Council Desk

Council Desk is a desktop app for Claude Code. It runs Claude Code on this Mac and keeps your sessions, settings and memory in Claude Code's own config folder.

The supported way to use it is an Anthropic API key. Usage is billed to your own Anthropic Console account at API rates. Create a key in the Console.

The key is saved encrypted, with the encryption key held in your macOS Keychain, and the app gives it only to Claude Code, whose commands can read it. You can also start the app from a terminal with ANTHROPIC_API_KEY set.

Already use Claude Code with another setup it supports, such as Amazon Bedrock or Google Vertex AI? Council Desk uses the same configuration and environment.
